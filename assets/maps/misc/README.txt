bs-schwarzer-berg.xodr
------------------------

OpenDRIVE road network dataset of Schwarzer Berg in Brunswick, v1.0.0 (2025).

Source:
  Scholz, M., Böttcher, O., Schäfer, J. P., Andert, F., iMAR Navigation GmbH (DLR).
  OpenDRIVE road network dataset of Schwarzer Berg in Brunswick, v1.0.0.
  Zenodo. https://doi.org/10.5281/zenodo.15395840

License: Creative Commons Attribution 4.0 International (CC BY 4.0)
  https://creativecommons.org/licenses/by/4.0/

This file is included in the Scenic test suite to ensure compatibility with
real-world OpenDRIVE maps that use paramPoly3 geometries with pRange="arcLength".
